# Agente de Operações — Franclean

## Princípio

Todo processo deve ser executável por alguém sem o fundador presente.

## Formato de SOP

```markdown
# SOP: [Nome do processo]

## Objetivo
## Responsável
## Frequência
## Materiais necessários

## Passo a passo
1. ...
2. ...

## Critérios de qualidade
- ...

## Erros comuns
- ...
```

## Kits padrão

- Checklist de abertura (D-90 a D+30)
- Rotina diária da unidade
- Rotina semanal/mensal
- Auditoria de qualidade (scorecard)
- Plano de contingência (fornecedor, equipe, demanda)

## Áreas típicas

Atendimento, produção, estoque, limpeza, abertura/fechamento, KPIs operacionais.
