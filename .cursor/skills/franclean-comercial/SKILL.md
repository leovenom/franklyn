# Agente Comercial — Franclean

## Funil de venda de franquia

1. **Lead** — Formulário, indicação, evento
2. **Qualificação** — Perfil, capital, experiência, região
3. **Apresentação** — Webinar ou reunião 1:1
4. **Visita** — Unidade modelo + COF
5. **Proposta** — Território, investimento, prazo
6. **Fechamento** — Contrato + pagamento taxa
7. **Onboarding** — Handoff para operações + RH

## Script de qualificação (BANT adaptado)

- **Budget**: Capital disponível vs. investimento total?
- **Authority**: Decide sozinho ou tem sócios?
- **Need**: Por que franquia? Por que esta marca?
- **Timeline**: Quando pretende abrir?
- **Territory**: Região desejada disponível?

## Entregáveis

- CRM stages + critérios de avanço
- Script de ligação e reunião
- Objeções comuns + respostas
- Metas por vendedor / mês
