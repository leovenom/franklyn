# Playbook de Franqueamento Franclean

## Fase 1 — Diagnóstico (1–2 semanas)

**Objetivo**: Decidir se franqueia agora, depois ou nunca.

Checklist de franqueabilidade (score 0–10 cada):

- [ ] **Replicabilidade** — Outra pessoa consegue operar sem o fundador?
- [ ] **Margem** — Unidade franqueada atinge payback ≤ 24 meses?
- [ ] **Marca** — Nome reconhecido ou diferenciado o suficiente?
- [ ] **Demanda** — Mercado absorve novas unidades?
- [ ] **Documentação** — Processos existem (mesmo que informais)?
- [ ] **Supply chain** — Fornecedores escaláveis?
- [ ] **Regulação** — Licenças e compliance mapeados?

**Score ≥ 49/70**: Prosseguir. **35–48**: Ajustar antes. **< 35**: Não franquear ainda.

## Fase 2 — Estruturação (3–6 semanas)

Entregáveis:

1. Modelo financeiro (taxa de franquia, royalties, fundo de marketing)
2. Manual de operações (SOPs por área)
3. Manual do franqueado
4. Plano de treinamento (presencial + EAD)
5. Kit de abertura (checklist 90 dias)
6. COF + contrato de franquia (jurídico)
7. Identidade visual e materiais de captação

## Fase 3 — Lançamento (4–8 semanas)

1. Landing page + formulário de interessados
2. Processo comercial (qualificação → visita → fechamento)
3. Primeiros 1–3 franqueados piloto
4. Ajustes pós-feedback

## Fase 4 — Escala

1. Expansão territorial (mapa de exclusividade)
2. Master franchise (regiões grandes)
3. Otimização de royalties e mix de receita
4. Internacionalização (quando aplicável)

## Métricas de sucesso da rede

| Métrica | Meta |
|---------|------|
| Taxa de churn de franqueados | < 5%/ano |
| NPS franqueados | > 50 |
| Tempo médio de abertura | < 90 dias |
| Unidades no break-even | ≤ 18 meses |
