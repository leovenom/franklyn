# SOP-02 — Onboarding academia parceira

| Campo | Valor |
|-------|-------|
| **Versão** | 1.0 |
| **Owner** | Comercial Pulse Box |
| **SLA** | Operacional em 21 dias pós-assinatura |

## Pipeline

```
Lead → Visita → Proposta → Contrato → Certificação → Go-live
```

## Passos

### 1. Qualificação (D-14)
- [ ] Academia operando ≥ 12 meses
- [ ] ≥ 150 m² área treino
- [ ] Owner disponível para reunião
- [ ] Sem exclusividade concorrente método box

### 2. Visita técnica (D-7)
- Layout · equipamentos mínimos (barra, rack, kettlebells, rower)
- Slot horário dedicado Pulse (mín. 6 turmas/sem)
- Foto área + checklist PB-INFRA

### 3. Contrato + pagamento (D-0)
- Taxa R$ 30.000 — 50% assinatura · 50% go-live
- Agendar certificação 2 coaches

### 4. Setup (D+1 a D+14)
- App white-label configurado
- Material marketing "Powered by Pulse Method™"
- WODs semana 1–4 liberados no portal

### 5. Go-live (D+21)
- 1ª turma com auditor Pulse (remoto ou presencial)
- NPS alunos ≥ 50
- Royalty reporting ativo

## KPIs parceiro ano 1

- ≥ 6 turmas/semana
- ≥ 80 alunos/mês passando turmas Pulse
- Churn licença: 0
