## Modelo alternativo: licenciamento B2B

Licenciar **Pulse Method™** para academias existentes — não abrir boxes novos.

```
Pulse Box (Itaim) ──► certifica coaches ──► academias parceiras usam método + marca
```

### Parceiro ideal
- Academia funcional/crossfit 150–400 m² **já operando**
- Owner quer diferencial de programação
- ≥ 2 coaches disponíveis para certificação

### O que o parceiro recebe
- Manual Pulse Method (periodização 12 semanas)
- Certificação PB-COACH-L1
- Uso marca "Powered by Pulse Method™"
- App WODs + leaderboard white-label
- 2 visitas auditoria/ano

### O que Pulse Box recebe
- Taxa licença: **R$ 30.000** (€ 5.000) one-time
- Royalty: **3%** receita turmas Pulse na unidade parceira
- Sem CAPEX de obra · sem aluguel novo
