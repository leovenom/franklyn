# SOP-02 — Fechamento e caixa

| Campo | Valor |
|-------|-------|
| **Versão** | 1.0 |
| **Owner** | Gerente de turno |
| **SLA** | Fechamento completo em **45 min** pós-último cliente |
| **Horário ref.** | Último pedido 20:30 · loja fecha 21:00 |

## Objetivo

Encerrar operação com caixa conciliado, equipamentos preservados e loja segura para o turno seguinte.

## Passos

### 1. Últimos pedidos (T-30 min)
1. Anunciar "last call" 30 min antes
2. Desligar vitrine quente 15 min antes do fechamento
3. Não aceitar pedidos após horário — exceção: takeaway já pago

### 2. Limpeza operacional (T-0 a T+25)
1. Limpar máquina espresso: backflush com detergent · grupos
2. Esvaziar knock box · limpar estações
3. Sanitizar mesas, balcão, banheiro (checklist GC-LIMPEZA-FECH)
4. Descartar alimentos fora validade — registrar desperdício

### 3. Estoque rápido (T+20)
1. Contagem visual insumos críticos (leite, café moído, cups)
2. Registrar pedido automático se abaixo par mínimo
3. Armazenar insumos abertos conforme ficha (geladeira/fechado)

### 4. Caixa e PDV (T+25 a T+40)
1. Fechar turno PDV · imprimir relatório Z
2. Contar gaveta: notas + moedas + vouchers
3. Conciliar: PDV vs físico vs PIX/cartão (extrato adquirente D+0 se disponível)
4. Diferença > R$ 20: registrar ocorrência + justificativa

```
Fórmula: Fundo troco + vendas dinheiro - sangrias = contagem física
Tolerância: ± R$ 5 sem ocorrência
```

### 5. Depósito e segurança (T+40)
1. Separar fundo troco R$ 200 para manhã seguinte
2. Excedente em envelope numerado · cofre ou transporte valores (conforme política franqueado)
3. Desligar máquinas (espresso última — após limpeza)
4. Alarme · travas · registrar horário saída

### 6. Handover
1. WhatsApp gerente/franqueado: resumo vendas turno + ocorrências
2. Planilha GC-FECHAMENTO assinada digitalmente

## Evidências

- Relatório Z PDV
- Planilha conciliação assinada
- Foto checklist limpeza (auditoria amostral)

## KPIs

- Conciliação caixa diária: 100% turnos
- Diferença média caixa: < R$ 10
- Tempo fechamento: ≤ 45 min

## Exceções

- Sistema PDV offline: vendas manuais + conciliação D+1 prioritária
- Assalto/emergência: protocolo segurança (Cap. jurídico manual) — não resistir
