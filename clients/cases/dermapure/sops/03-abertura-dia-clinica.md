# SOP-03 — Abertura do dia clínica

| Campo | Valor |
|-------|-------|
| **Versão** | 0.9 |
| **Owner** | Gerente clínica |
| **SLA** | Pronta 30 min antes 1º cliente |

## Checklist manhã

### Infra (T-30)
- [ ] Salas sanitizadas · macas com lençol limpo
- [ ] Equipamentos calibrados (vapor, LED, dermapen esterilizado)
- [ ] Produtos Tier A dentro validade · FIFO

### Recepção (T-20)
- [ ] PDV aberto · confirmações WhatsApp D-1 enviadas
- [ ] Fichas anamnese tablet carregado
- [ ] Estoque mínimo produtos venda (home care)

### Equipe (T-15)
- [ ] Biomédico uniforme · certificação vigente
- [ ] Briefing: agenda dia + casos especiais
- [ ] Fundadora (se Tier B): casos sinalizados

## Fechamento dia (pós-último cliente)

1. Esterilização instrumentos · descarte resíduos infectantes (RDC)
2. Conciliação caixa · comissões
3. Log procedimentos CRM · fotos upload
4. Agenda D+1 confirmada

## KPIs

- No-show: < 8%
- Ocupação agenda: 75–85%
