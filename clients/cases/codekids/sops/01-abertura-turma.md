# SOP-01 — Abertura de turma

| Campo | Valor |
|-------|-------|
| **Versão** | 1.0 |
| **Owner** | Coordenador regional |
| **Frequência** | A cada novo ciclo trimestral ou turma adicional |
| **SLA** | Turma operacional 5 dias úteis antes da 1ª aula |

## Objetivo

Garantir que toda turma nova atinja capacidade mínima (6 alunos), tenha instrutor certificado, sala configurada e comunicação aos pais antes do início.

## Gatilho

- Meta de matrículas atingida para trilha + faixa etária, **ou**
- Lista de espera ≥ 6 alunos para mesma trilha/horário

## Pré-requisitos

- [ ] Instrutor com certificação EAD válida (trilha correspondente)
- [ ] Sala aprovada em checklist de infra (SOP anexo infra)
- [ ] CRM com mínimo 6 matrículas confirmadas (pagamento 1ª mensalidade ou sinal)

## Passos

### 1. Planejamento (D-15)
1. Definir trilha (Scratch / Python / Web), faixa etária e horário fixo (ex.: ter/qui 17h–18h30)
2. Reservar sala e instrutor no sistema interno
3. Abrir vagas no CRM — máximo 12, mínimo para abrir: 6

### 2. Captação final (D-15 a D-7)
1. Disparar campanha "últimas vagas" para lista de espera
2. Confirmar pagamento de todos os matriculados
3. Se < 6 alunos em D-7: **postergar** abertura 2 semanas ou **mesclar** com turma existente (mesma trilha)

### 3. Setup pedagógico (D-7 a D-5)
1. Coordenador aloca módulo trimestral no portal EAD
2. Instrutor revisa plano de aula das 12 sessões
3. Separar kits (Chromebook/posto, material impresso se aplicável)
4. Testar login de todos os alunos no portal

### 4. Comunicação (D-5)
1. E-mail/WhatsApp template **CK-BOAS-VINDAS-TURMA** para pais
2. Incluir: endereço, horário, instrutor, código portal, política reposição
3. Agendar mensagem lembrete D-1 (automático CRM)

### 5. Go-live (D-0)
1. Check-in presencial — lista impressa + CRM
2. Foto turma (autorização LGPD prévia) — opcional marketing
3. Registrar presença no portal
4. Pós-aula: NPS rápido pais (1 pergunta, escala 0–10)

## Evidências

| Evidência | Onde arquivar |
|-----------|---------------|
| Print CRM turma ≥ 6 alunos | Pasta `Turmas/AAAA-TX/` |
| Certificado instrutor EAD | RH instrutores |
| Checklist sala assinado | Drive operacional |
| Log comunicação pais | CRM histórico |

## Exceções

| Situação | Ação |
|----------|------|
| Instrutor desistente D-3 | Acionar SOP-03 substituição |
| Sala indisponível | Coworking backup homologado (lista franqueadora) |
| Aluno extra após D-5 | Máximo +2 se turma < 12; senão lista espera |

## KPIs

- Taxa turmas canceladas por baixa matrícula: **< 5%**
- Tempo médio abertura (gatilho → 1ª aula): **≤ 21 dias**
