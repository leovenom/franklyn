# Brief — CodeKids

## Negócio

- **Marca**: CodeKids
- **Segmento**: Educação — programação para crianças 7–14 anos
- **Unidades**: 3 próprias (Pinheiros-SP, Campinas, Ribeirão Preto)
- **Faturamento**: ~R$ 800.000/unidade/ano (€ 133.000)
- **Modelo**: Mensalidade R$ 280–420/aluno · turmas 8–12 alunos

## Fundador

- **Perfil**: 2 sócios — 1 pedagogo, 1 dev; operação delegada a coordenadores regionais
- **Dependência**: Baixa no dia a dia das unidades

## Objetivo

- Expandir para 20 unidades em 24 meses (Sudeste → interior)
- Mercado: **Brasil** (prioritário)

## Diferenciais

- Currículo próprio modular (Scratch → Python → web)
- Portal EAD para formação de instrutores
- NPS pais: 62
